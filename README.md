# HMS Frontend & Backend (Hospital / Hotel Management System)

A full-stack Hospital / Hotel Management System built with **React.js frontend** and **Python Django REST Framework backend**.

---

## 🌐 Live Demo

- Frontend: [HMS Frontend](https://hmsfrontend-cyan.vercel.app)  

---

## 🚀 Features

### Frontend (React.js)
- Responsive UI: Login, Signup, Dashboard  
- Role-based access (Admin, Staff, Manager)  
- Dashboard analytics & tables  
- Reusable components and forms  
- Mobile-friendly layouts  

### Backend (Python Django REST Framework)
- RESTful APIs for all modules  
- Role-based permissions and authentication  
- JWT authentication for secure API access  
- CRUD operations for Users, Rooms, Attendance, etc.  
- Audit logs and activity tracking  

---

## 🛠 Tech Stack

| Layer        | Technologies / Tools |
|--------------|-------------------|

| Database     | MySQL / SQLite |
